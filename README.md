# Mystery Box

Bu paket yeni bir GitHub repository için hazırlanmıştır.

## MP3 ekleme
1. MP3 dosyanızın adını `music.mp3` yapın.
2. Dosyayı `audio` klasörüne koyun.
3. GitHub'a tüm klasör ve dosyaları yükleyin.

Doğru konum:
`audio/music.mp3`

Site müzik olmadan da çalışır. MP3 eklendiğinde ilk kutu dokunuşunda müzik başlar.
